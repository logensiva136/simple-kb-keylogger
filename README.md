# Fancy Keyboard (Android, Java)

1. Open this folder in Android Studio (Koala or newer) and let Gradle sync.
2. Run on a device/emulator (minSdk 24).
3. In the app: **Enable keyboard** -> toggle "Fancy Keyboard", then **Switch to Fancy Keyboard**.

Features: 3 gradient themes (tap 🎨), ripple + key pop-up animations, haptics,
shift / double-tap caps lock, auto-capitalise, symbols layer, hold-to-repeat delete.
